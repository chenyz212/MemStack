# 统一 AI 记忆桌面客户端第三轮验收报告



## 一、交付结论



第三轮 `0.4.0` 已完成核心实现并生成 Windows x64 绿色版。桌面 REST 固定使用 `127.0.0.1:18461`，MCP Streamable HTTP 永久固定使用 `127.0.0.1:10212/mcp`，两类服务已完成端口隔离和进程级验收。



## 二、已完成内容



\- 使用 ModelContextProtocol 2.0.0 与 ModelContextProtocol.AspNetCore 2.0.0。

\- 实现固定 10212 无状态 Streamable HTTP 和不监听端口的 stdio 模式。

\- 实现只读、读写、项目范围和过期 Token 权限。

\- Token 使用 Windows DPAPI CurrentUser 加密，可长期重新查看、复制、吊销和重新生成。

\- 连接 AI 页面提供 Codex、Claude、Cursor、Trae、通用 MCP 五张独立卡片。

\- Token 默认雾化，悬停或聚焦显示；鼠标移出、失焦、窗口失焦、菜单切换和 Esc 后恢复隐藏。

\- 实现 16 个固定名称、单一职责 MCP 工具。

\- 实现正式记忆和候选提交双通道，以及候选编辑、乐观锁确认、拒绝和去重。

\- MCP 写入来源严格取自 Token 显示名，工具参数不能覆盖来源。

\- 总览展示待确认数量、10212 服务状态、最近 AI 助手和最近 MCP 调用时间。

\- 端口占用时不随机漂移，释放后可以单独重启 MCP 服务。



\## 三、自动化测试



\- TypeScript 类型检查：通过。

\- Vitest：3 个测试文件、14 项测试全部通过。

\- Vue 生产构建：通过。

\- 数据库增量升级、候选事务、权限和二万条数据检索测试：通过。



性能测试曾出现一次 P95 107ms 的边界波动，单独复测及完整复测均通过 100ms 目标，未放宽验收阈值。



\## 四、最终 EXE 实机验收



\- 隐藏启动最终绿色版后，18461 与 10212 同时监听。

\- `GET http://127.0.0.1:18461/api/health` 返回 200。

\- 10212 MCP 无 Bearer Token 请求返回 401。

\- 10212 不暴露桌面 REST 管理接口。

\- 通过应用退出事件完全退出后，18461 与 10212 均不再监听。

\- stdio 使用无效 Token 时 stdout 为 0 字节，错误只写 stderr，且两个端口均未监听。
