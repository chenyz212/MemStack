# 工作空间记忆链路与记忆页重构执行计划

## 一、目标

- 建立“本地工作空间 → 中文项目”的稳定绑定。
- 首次从工作空间保存项目记忆时要求 AI 询问中文项目名。
- 后续从相同工作空间保存时自动归入已绑定项目。
- 无法取得工作空间时要求用户选择个人记忆或已有项目，禁止猜测。
- 重构记忆页，明确区分全部、个人、项目、置顶、收藏和归档记忆。
- 修复总览搜索结果被首页卡片裁切的问题。

## 二、固定决策

- 一个工作空间对应一个中文项目，一个项目最多绑定一个工作空间。
- 同名且未绑定的活动项目优先复用。
- 不根据目录名称自动生成中文项目名。
- AI 调用工具时显式携带工作空间 URI；旧 MCP Roots 能力仅作为兼容来源。
- 工作空间缺失时必须询问用户，不默认保存到个人记忆。
- 使用 SQLite 增量迁移，不删除或覆盖现有桌面数据。

## 三、执行内容

1. 为项目增加工作空间键、URI、简称和最近使用时间。
2. 实现 Windows 路径与 `file://` URI 的统一标准化和哈希。
3. 实现工作空间解析、绑定、解绑和首次项目命名流程。
4. 扩展项目列表与记忆分类统计接口。
5. 扩展记忆列表的收藏、置顶筛选。
6. 将记忆页重构为“记忆分类、快捷访问、项目空间”三级结构。
7. 将首页搜索结果移动到页面顶层浮层，支持自动定位和键盘操作。
8. 补充数据库升级、工作空间链路、分类筛选和前端结构测试。
9. 完成前后端构建并重新生成 Windows 绿色版 EXE。

## 四、验收标准

- 首次未绑定工作空间返回需要项目名称的结构化结果，不写入记忆。
- 提供中文项目名后完成绑定和保存，后续相同空间不再询问。
- 路径大小写、斜杠和末尾分隔符变化仍识别为同一空间。
- 记忆页明确显示个人记忆和项目记忆，所有分类数量正确。
- 首页搜索结果在常用窗口尺寸和缩放比例下不被裁切。
- 现有记忆、项目、历史版本、检索和模型设置功能保持可用。
