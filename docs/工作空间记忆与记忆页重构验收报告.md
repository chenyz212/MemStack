# 工作空间记忆与记忆页重构验收报告

## 一、完成内容

- SQLite 结构升级至版本 2，新增项目工作空间绑定字段和唯一索引。
- 实现 Windows 路径与文件 URI 标准化、稳定哈希和一对一绑定。
- 实现首次询问中文项目名、同名未绑定项目复用和后续自动归类。
- 新增轻量 MCP HTTP 入口及 `workspace_resolve`、`memory_store`、`memory_search` 三个工具。
- MCP 使用独立 Bearer Token，Token 由 DPAPI 加密保存在当前 Windows 用户目录。
- 记忆页重构为记忆分类、快捷访问和项目空间三个区域。
- 明确增加个人记忆、项目记忆、置顶、收藏和已归档入口及数量。
- 项目编辑支持绑定、修改和解除工作空间。
- 首页搜索结果改为页面顶层浮层，不再受首页卡片裁切。
- 连接 AI 页面提供真实 MCP 状态、地址、令牌和完整配置复制。
