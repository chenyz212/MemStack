# 统一 AI 记忆桌面客户端第二轮验收报告

## 一、交付结论

第二轮核心功能已经落地为可直接双击运行的 Windows x64 绿色版客户端。应用不需要 Java、Node.js、Docker 或外部数据库，打开后直接进入总览，不包含登录页。数据存储在当前 Windows 用户目录的 SQLite 数据库中。

本轮完成：

- SQLite、WAL、FTS5 和十张规划表。
- 个人记忆、项目记忆、快速记录、编辑、归档与恢复。
- 项目创建、修改、归档与恢复。
- 乐观锁、内容去重、最近十个历史版本和历史恢复。
- 中文单字与二元词组检索、字段加权、模糊回退和匹配原因。
- 可选 OpenAI 兼容 Embedding、DPAPI、后台向量任务、Weighted RRF、MMR 与上下文预算。
- 总览、记忆管理、项目筛选、收藏、置顶、模型设置和主题切换。
- 桌面临时访问密钥、仅监听本机地址、单实例、托盘与快速退出。
- 删除独立搜索导航、动态效果按钮和所有动画切换代码；克制动画始终启用。

按计划留到后续轮次：MCP 正式接入、候选记忆、正式可视化图谱、备份恢复和安装程序。

## 二、问题修复

真实 EXE 冒烟发现首次数据库建表中断后，再次启动会报错：

```text
SQLite Error 1: 'table app_setting already exists'
```

根因包括两种情况：部分表已经落盘但结构版本仍为零，以及旧 Java 版 SQLite 数据库与新桌面库同名。数据库初始化现已改为可重复执行的修复式初始化，并在启动时检查真实字段结构。检测到旧 Java 数据库时完整保留 `memory.db`，桌面版自动改用 `desktop-memory.db`，不迁移也不覆盖旧数据。

检索性能首次实测二万条数据 P95 为 161ms。优化 FTS5 原生排名快速路径后，同一基准 P95 为 40ms，达到小于 100ms 的目标。

## 五、已知边界

- 当前是绿色免安装版，不是带安装目录选择的安装程序。
- 依赖系统 WebView2 Runtime；当前测试系统已具备并验证通过。
- Embedding 真实调用需要用户自行提供兼容 API，未配置时自动使用关键词模式。
- 本轮没有可用的真实 Embedding API 凭据，因此网络模型正确性由 Mock、维度校验和本地融合算法测试覆盖，未执行真实供应商付费请求。
- 一百条人工标注中文检索集和混合 Recall/MRR 尚未形成稳定基准资产，留作检索专项优化，不阻塞个人日常版交付。
