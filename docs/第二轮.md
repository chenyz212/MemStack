# 统一 AI 记忆桌面客户端第二轮执行计划（最终修订版）

## 一、目标

第二轮把当前静态桌面外壳升级为可日常使用的本地记忆客户端：

- 使用 SQLite + FTS5 保存个人记忆、项目记忆和历史版本。
- 实现中文关键词检索、可选 Embedding 语义检索和混合排序。
- 实现真实的快速记录、记忆管理、项目筛选和模型设置。
- 总览接入真实数据。
- 搜索并入总览，导航缩减为五项。
- 删除“动态效果”按钮及相关控制代码。
- 保留当前克制的页面动画，动画始终启用。
- 不加入深空粒子、Canvas 动态背景、节点避让等高级环境动画。
- 不迁移 PostgreSQL 数据，不复用 Java 业务实现。

预计工期：6～8 个工作日。

## 三、第二阶段：SQLite 数据基础

### 数据库

使用：

- `Microsoft.Data.Sqlite`。
- SQLite FTS5。
- 原生参数化 SQL。
- `PRAGMA user_version` 管理数据库版本。
- WAL 模式。
- 事务写入。

数据库位置：

```
%LOCALAPPDATA%\UnifiedAiMemory\data\memory.db
```

启动配置：

```
PRAGMA foreign_keys = ON;
PRAGMA journal_mode = WAL;
PRAGMA synchronous = NORMAL;
PRAGMA busy_timeout = 5000;
```

### 数据表

建立总体计划规定的 10 张表：

```
app_setting
project
memory
memory_revision
memory_embedding
memory_edge
memory_candidate
mcp_token
background_task
memory_fts
```

第二轮启用：

- `app_setting`
- `project`
- `memory`
- `memory_revision`
- `memory_embedding`
- `background_task`
- `memory_fts`

其余表仅提前建好结构，不开放业务功能。

### 核心规则

- 所有主键使用 UUID。
- 时间统一保存为 UTC。
- 个人记忆不能关联项目。
- 项目记忆必须关联有效且未归档项目。
- 项目名称忽略大小写后唯一。
- 重要程度限制为 1～5。
- 正文最大 200000 字符。
- 相同范围、项目和内容哈希不能重复。
- 每条记忆最多保留最近 10 个历史版本。
- 归档记忆不会自动删除。

### 代码结构

API 项目按职责拆分：

```
Domain
Application
Infrastructure
Endpoints
```

不引入 EF Core、Dapper、仓储接口套娃或旧 Java 企业级结构。

### 验收

- 首次启动自动创建数据库。
- WAL 模式生效。
- 重启后数据完整。
- 事务失败不留下半写入数据。
- FTS 与记忆主表保持一致。
- 数据只写入当前 Windows 用户目录。

## 四、第三阶段：记忆、项目和版本闭环

### 项目

实现：

- 创建和修改项目。
- 设置名称、说明和颜色。
- 归档和恢复项目。
- 查询活动和归档项目。
- 归档项目不能接收新记忆。
- 项目归档不自动归档已有记忆。

### 记忆

实现：

- 创建个人和项目记忆。
- 修改标题、摘要、正文、类型、标签和重要程度。
- 在个人与项目范围之间移动。
- 收藏、置顶、归档和恢复。
- 设置是否允许云端处理。
- 内容哈希精确去重。
- 使用 `expectedVersion` 乐观锁。
- 版本冲突返回 HTTP 409。

### 历史版本

- 创建记忆时生成版本 1。
- 修改业务内容前保存旧快照。
- 恢复历史时创建新版本。
- 不覆盖旧历史。
- 每条记忆最多保留 10 个版本。
- 收藏和置顶变化不生成正文版本。

### 快速记录

总览快速记录接入真实数据：

- 默认保存为个人记忆。
- 正文第一行前 60 个字符作为默认标题。
- 不调用文本模型生成标题。
- `Ctrl+Enter` 保存。
- 保存期间禁止重复提交。
- 保存成功后清空输入框。
- 刷新总览数量和最近记忆。
- 重复内容提示并打开已有记忆。

## 五、第四阶段：中文关键词检索

### 文本处理

保存和查询统一执行：

- Unicode NFKC 标准化。
- 英文转小写。
- 合并连续空白。
- 移除无检索意义的标点。
- 保留原始中文文本。
- 生成中文单字和相邻二元词组。
- 保留英文、数字、路径和版本号。
- 去除重复词元。

### FTS5 权重

```
标题：5
关键词和标签：4
摘要：3
正文：1
```

### 检索规则

- 标题完全一致必须排第一。
- 支持中文单字、短词和二元词组。
- 支持英文、数字前缀和中英文混合查询。
- 项目、范围、状态、类型和标签在 SQL 召回前过滤。
- 空查询不进入 FTS。
- 无有效结果时才执行模糊回退。
- 模糊回退仅检查标题、关键词和摘要。
- 模糊回退限制候选数量。

### 匹配原因

返回：

```
TITLE_EXACT
TITLE_PREFIX
KEYWORD
TAG
SUMMARY
CONTENT
FUZZY
SEMANTIC
```

前端展示对应中文原因。

## 六、第五阶段：Embedding 与混合检索

### 模型设置

设置页实现：

- OpenAI 兼容 API 地址。
- 模型名称。
- API Key。
- 向量维度。
- 启用或禁用语义检索。
- 测试连接。
- 重新生成全部向量。

规则：

- API Key 使用 Windows DPAPI 加密。
- 前端只返回掩码。
- 日志不记录 Key 或记忆正文。
- 保存前必须测试成功。
- 返回维度必须与配置一致。
- 维度范围为 128～1536。
- 模型配置变化后重建向量。
- 模型异常时自动退回关键词检索。

### 向量处理

- 只处理允许云端处理的记忆。
- 使用标题、摘要、关键词、标签和正文生成向量。
- 内容未变化时不重复生成。
- 使用标准化 `float32` 二进制存储。
- 使用 `System.Numerics.Vector<float>` 计算相似度。
- 查询向量缓存 10 分钟。
- 切换为仅本地时删除向量。
- 后台失败最多重试 3 次。
- 成功任务立即删除。
- 失败任务最多保留 20 条。

### 排序

第二轮权重：

```
关键词：60%
语义：35%
元数据：5%
```

语义不可用时：

```
关键词：95%
元数据：5%
```

使用 Weighted RRF，并保证：

- 标题精确匹配优先。
- 元数据权重不超过 5%。
- 重复和近重复结果受到抑制。
- 不根据访问次数调整排序。

### 上下文组装

固定参数：

```
MMR 相关性：0.72
MMR 多样性：0.28
默认字符预算：8000
最大字符预算：30000
关联扩展数量：0
```

不调用文本模型二次总结。

## 七、第六阶段：REST API 和本地访问保护

### 本地管理密钥

- WPF 每次启动生成随机临时密钥。
- 密钥只保存在内存。
- WebView 通过 URL Fragment 接收。
- Vue 读取后清除 Fragment。
- 管理 API 携带：

```
X-Unified-Memory-Desktop-Key
```

- 除健康检查外，错误密钥返回 401。
- API 继续只监听 `127.0.0.1`。
- 第三轮 MCP 使用独立 Bearer Token。

### 接口

项目：

```
GET    /api/projects
POST   /api/projects
PUT    /api/projects/{id}
POST   /api/projects/{id}/archive
POST   /api/projects/{id}/restore
```

记忆：

```
GET    /api/memories
GET    /api/memories/{id}
POST   /api/memories
PUT    /api/memories/{id}
POST   /api/memories/{id}/archive
POST   /api/memories/{id}/restore
GET    /api/memories/{id}/revisions
POST   /api/memories/{id}/revisions/{version}/restore
```

检索：

```
POST /api/search
POST /api/search/context
```

总览：

```
GET /api/overview
```

模型：

```
GET  /api/settings/embedding
POST /api/settings/embedding/test
PUT  /api/settings/embedding
POST /api/settings/embedding/rebuild
GET  /api/settings/embedding/status
```

错误统一返回：

```
{
  "code": "MEMORY_VERSION_CONFLICT",
  "message": "记忆已被其他操作修改，请刷新后重试",
  "details": {}
}
```

列表使用游标分页，默认 30 条，最大 100 条。
