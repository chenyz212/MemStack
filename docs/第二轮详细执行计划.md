# 统一 AI 记忆桌面客户端第二轮执行计划

本轮按照已确认的“最终修订版”执行：删除动态效果按钮与独立搜索导航，保留始终启用的克制动画；使用 SQLite、FTS5 和可选 Embedding API 实现个人与项目记忆、历史版本、混合检索、上下文组装、真实总览和模型设置。MCP、候选确认、正式图谱、备份恢复与 Java 数据迁移不在本轮范围。

执行阶段：

1. 清理第一轮导航与动画开关遗留。
2. 创建十张精简数据表并启用 WAL、外键和 FTS5。
3. 实现项目、记忆、历史版本、归档恢复与快速记录。
4. 实现中文单字/二元词组索引、字段加权检索和模糊回退。
5. 实现 Embedding 配置、DPAPI、向量存储、混合排序和上下文预算。
6. 实现桌面临时访问密钥与 REST API。
7. 接入真实总览、搜索、记忆与设置页面。
8. 完成自动化测试、性能验收、EXE 发布和中文验收报告。

验收以用户确认的完整第二轮计划为准。
