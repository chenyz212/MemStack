# 忆栈 0.4.0 用户升级说明（C# → Rust 版）

> 适用对象：正在使用 C# 0.4.0（统一 AI 记忆）及更早版本的用户
> 发布形态：安装版（忆栈_0.4.0_x64-setup.exe）与绿色版（MemStack-Portable-0.4.0）

## 一、版本变化概览

0.4.0 Rust 版在功能与数据上与 C# 版完全等价（45 项桌面功能 + 16 个 MCP 工具），核心变化：

| 项 | C# 旧版 | Rust 新版 |
|---|---|---|
| 桌面框架 | WPF + WebView2 | Tauri + WebView2（体积 85.81MB → 约 18MB） |
| 本地端口 | 监听 18461（桌面）与 10212（MCP） | **不监听任何端口** |
| AI 客户端接入 | HTTP/stdio 混合 | 标准 **MCP stdio**（MemStack-MCP.exe） |
| 数据库 | SQLite schema 7 | 同一文件、同一 schema，**无需迁移** |
| 凭据加密 | DPAPI | 同一 DPAPI 密文，**无需重新填写密钥** |

## 二、升级前准备

1. 退出正在运行的旧版：托盘图标右键 → 退出（确认任务管理器中无「统一AI记忆」/「UnifiedAiMemory」进程）。
2. 建议手动做一次数据目录快照：复制 `%LOCALAPPDATA%\UnifiedAiMemory` 整个目录到任意备份位置。
3. 确认系统已安装 Microsoft Edge WebView2 Runtime（Win11 默认自带；Win10 可从微软官网安装）。

## 三、升级步骤（安装版）

1. 双击 `忆栈_0.4.0_x64-setup.exe`（当前用户安装，无需管理员权限）。
2. 默认安装到 `%LOCALAPPDATA%\Programs\忆栈`，包含 `忆栈.exe` 与 `MemStack-MCP.exe`。
3. 启动「忆栈」：
   - 首次启动会**自动创建数据库一致性备份**（见下节），随后正常进入主界面；
   - 旧版窗口位置、大小、最大化状态自动继承（同一份 window-state.json）。
4. 若此前已为 Codex/Claude/Cursor 写入过接入配置，进入「连接你的 AI」页面：
   - 配置仍指向有效路径时无感继续使用；
   - 若显示黄色「程序位置已变化」警示，点击**一键重新注册**即可修复（自动备份原配置）。

## 四、升级步骤（绿色版）

1. 解压 `MemStack-Portable-0.4.0` 到任意目录。
2. 运行目录内 `忆栈.exe`。
3. 注意：绿色版注册的接入配置使用**当前绝对路径**；移动目录后配置会失效，页面会出现黄色警示，点击「一键重新注册」修复即可。

## 五、首次运行自动备份（内置安全网）

Rust 版第一次写入生产数据库前会自动执行：

```text
%LOCALAPPDATA%\UnifiedAiMemory\backup\pre-rust-<时间戳>.db      一致性备份（Online Backup API）
%LOCALAPPDATA%\UnifiedAiMemory\backup\pre-rust-<时间戳>.db.sha256  校验和
%LOCALAPPDATA%\UnifiedAiMemory\backup\rust-first-run.marker     首启完成标记
```

- 备份经过完整性检查（integrity_check）与校验和比对，全部通过才会启动主程序；
- 备份目录最多保留 2 份 pre-rust 备份，更早的自动清理；
- 如需手动重触发：删除 marker 文件后下次启动重新备份。

## 六、回滚步骤（如遇问题）

1. 退出忆栈（托盘右键退出）与所有 AI 客户端（Codex 等），确保无 MemStack-MCP.exe 进程。
2. 卸载 Rust 版（安装版：控制面板卸载；绿色版：删除目录）。卸载**不会**删除 `%LOCALAPPDATA%\UnifiedAiMemory` 用户数据。
3. 恢复 C# 0.4.0 绿色版（或原目录直接运行）。
4. 由于 Rust 版未改动 schema（仍为 7），通常**直接切回即可**；仅当数据校验异常时：
   - 用备份目录中的 `pre-rust-<时间戳>.db` 覆盖 `%LOCALAPPDATA%\UnifiedAiMemory\data\memory.db`（覆盖前先删除同目录 `-wal`/`-shm` 文件并保留现场副本）。
5. 恢复 AI 客户端配置：各配置文件旁的 `*.bak.<时间戳>` 为写入前自动备份，改回原名即可。
6. 核对项目数、记忆数、候选数与检索结果。

## 七、常见问题

**问：升级后 API Key、MCP 令牌要重新填吗？**
不需要。DPAPI 密文在同一 Windows 用户下双向兼容。

**问：启动弹窗「创建首次运行备份失败」？**
通常是磁盘空间不足或备份目录被占用。清理 `%LOCALAPPDATA%\UnifiedAiMemory\backup` 后重试；详见《故障排查》。

**问：旧版还在监听端口，新版 MCP 怎么连？**
新版不监听端口。AI 客户端通过 stdio 启动 `MemStack-MCP.exe --session-id <会话ID>`，配置由「连接你的 AI」页面一键写入。

**问：环境变量令牌（UNIFIED_AI_MEMORY_TOKEN）还能用吗？**
0.4.0 仍兼容，但**将于 0.5.0 移除**。页面检测到旧形态会显示蓝色提示，点击「改用会话 ID」一键迁移。
