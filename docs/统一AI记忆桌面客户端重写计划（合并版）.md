# 统一 AI 记忆桌面客户端重写计划（合并版）

---

## 一、产品定位与总体方向

### 1.1 产品重心

新版本不再定位为"记忆管理后台"，而是：

> 一个以 MCP 接入、记忆检索和上下文召回为核心，附带可视化记忆图谱的个人桌面工具。

工程投入优先级：

1. MCP 兼容性和连接稳定性。
2. 中文与语义混合检索质量。
3. `memory_context` 上下文组装质量。
4. 可解释的记忆关系图谱。
5. 极简桌面操作。
6. 记忆管理和设置。
7. 其他辅助功能。

### 1.2 免登录与安全边界

桌面客户端不再有管理员账号、初始密码、登录页或 Web 会话。双击程序后直接进入"总览"首页。

- 本地管理界面默认无登录。
- MCP 仍使用独立 Bearer Token，防止其他 AI 客户端未经授权访问。
- 本地服务默认只监听 `127.0.0.1`，不对局域网开放。
- 不迁移当前 PostgreSQL 数据，使用全新的 SQLite 数据库。

安全边界：

| 访问方式 | 验证方式 |
| --- | --- |
| 桌面客户端管理界面 | 无登录，仅允许本机 |
| MCP Streamable HTTP | 独立 Bearer Token |
| MCP stdio | stdio 配置中提供 Token |
| 局域网访问 | 首版不支持 |
| 备份文件 | 用户自行保管，后续可增加备份密码 |

随免登录一并删除：登录页、账户页、管理员初始化、密码生成、会话、CSRF、退出登录、密码修改，以及与管理员身份相关的数据库字段、接口和前端状态。本地管理 API 仅允许来自客户端内嵌页面和本机回环地址的访问。

### 1.3 技术栈

- .NET 10、C#、WPF、WebView2（同进程运行）。
- ASP.NET Core 内嵌本地服务。
- Vue 3、TypeScript、原生 CSS。
- SQLite + FTS5，启用 WAL。
- 官方 C# MCP SDK（Streamable HTTP + stdio）。
- Inno Setup 安装包 + 便携绿色压缩包。
- 不使用 Electron、Java、PostgreSQL、Docker、Redis、消息队列、本地模型、Lucene 或大型图谱框架。

### 1.4 预计规模

| 项 | 规模 |
| --- | --- |
| C# 正式代码 | 6500–9000 行 |
| 自动化测试 | 3000–4500 行 |
| Vue 页面 | 约 3500–4500 行 |
| 数据表 | 10 张核心表 |
| REST API | 约 30 个 |
| MCP 工具 | 13 个 |
| 日常可用 Beta | 12–16 个工作日 |
| 完整发布版 | 28–40 个工作日（约 6–8 周） |

## 二、极简 UI 与功能取舍

### 2.1 导航：总览默认首页 + 四项，共五项

```
总览（默认首页）
记忆
图谱
连接 AI
设置
```

> 搜索不再单独占一个导航项：总览页内置全局搜索框，`Ctrl+K` 随时聚焦，全应用可用。详见附录 A 裁决 3。

#### 总览（默认首页）

免登录直接进入，以"搜索"为页面绝对主体，状态信息压缩展示：

- 全局搜索框：首页首要操作，`Ctrl+K` 聚焦，`Ctrl+N` 打开快速记录。
- 快速记录：无需跳转即可保存个人记忆。
- 一条紧凑状态行：记忆总数、项目数、待确认候选数。
- MCP 接入状态：客户端、读写权限、项目范围和最近调用时间。
- 小型图谱预览：18～30 个活跃记忆节点，可进入完整图谱。
- 最近记忆：最多 5 条。
- 活跃项目：最多 4 个。
- 待确认候选：仅有内容时展示。
- 首次使用时顶部显示可收起的引导：
  1. 创建第一条个人或项目记忆。
  2. 连接 AI 客户端。
  3. 可选配置 Embedding API。

不显示统计卡片、欢迎大图、动态记忆中枢仪表盘和企业仪表盘。

#### 记忆

一个页面完成：

- 个人记忆、项目记忆、待确认候选、归档记忆。
- 收藏和置顶。
- 项目作为左侧筛选，不再单独做项目管理页。
- 详情、编辑和历史版本使用右侧抽屉。
- 项目创建和修改使用小型弹窗。

#### 图谱

独立的极简画布：

- 默认显示当前记忆两跳邻域。
- 节点只代表记忆；项目通过节点颜色和背景分组表示。
- 不显示人物、技术、标签等实体节点，不建设复杂知识图谱。
- 图谱右侧使用窄详情面板。
- 从搜索结果和记忆详情均可打开图谱。

#### 连接 AI

作为核心页面：

- 选择 Codex、Claude、Cursor、Trae 或通用客户端。
- 创建只读或读写 Token，可选限制到指定项目。
- 一键复制 HTTP 配置、一键复制 stdio 配置、一键测试连接。
- 显示连接成功、最后调用时间和权限范围。
- 删除复杂客户端会话关联、孤立 Token 绑定和自动猜测逻辑。

#### 设置

只保留四个分组：

| 分组 | 内容 |
| --- | --- |
| 模型 | 文本 API、Embedding API、连接测试 |
| 数据 | 备份、恢复、导入、导出 |
| 安全 | Token 总览（无密码体系；可选"应用解锁密码"首版不实现，仅预留） |
| 应用 | 主题、开机启动、最小化到托盘 |

### 2.2 保留的功能

- 个人与项目记忆。
- 创建、修改、归档、恢复。
- 最近 10 个历史版本。
- 标签、类型、重要程度。
- 收藏和置顶。
- AI 候选记忆确认。
- 云端处理开关。

- Token 权限和项目范围。
- 模型 API 可选配置。
- 自动备份和手动恢复。
- Markdown、TXT、JSON 导入导出。
- 快速记录。
- 剪贴板内容手动预览保存。
- 首次使用引导。

### 2.3 删除的功能

- 独立项目页、独立任务页、独立导入页、独立账户页。

- 导入批次历史、备份任务记录。

## 三、检索、MCP 与图谱设计

### 3.1 检索流程

检索统一经过六步：

```
查询标准化
→ 范围识别
→ FTS5 关键词召回
→ Embedding 语义召回
→ 图谱邻居扩展
→ 融合、去重和上下文裁剪
```

#### 关键词召回

使用 SQLite FTS5：

- 标题权重：5。
- 关键词和标签权重：4。
- 摘要权重：3。
- 正文权重：1。
- 中文保存时生成单字、二元词组和原始文本。
- 支持标题精确匹配、支持前缀匹配。
- 无精确结果时才启用模糊回退。
- 项目、类型和标签过滤在召回前执行。

#### 语义召回

- Embedding API 可选。
- 向量以紧凑二进制存入 SQLite。
- 使用 C# `System.Numerics` SIMD 计算相似度。
- 默认优化 2 万条个人记忆。
- 查询向量缓存 10 分钟。
- 不配置模型时完全跳过。
- 仅本地记忆不生成或保留云端向量。
- 不引入实验性向量扩展和独立向量数据库。

#### 图谱召回

图谱只作为低权重补充：

- 先取得关键词和语义 Top 结果。
- 再扩展这些结果的一跳强关联记忆。
- 只有关联分达到阈值才进入候选。
- 图谱结果不能压过标题精确匹配。
- 防止图谱把查询扩展到无关项目。

#### 融合排序

默认权重：

```
关键词召回：50%
语义召回：35%
图谱关联：10%
重要度等元数据：5%
```

- 语义不可用时，权重自动分配给关键词召回。
- 使用 Weighted RRF 融合。
- 内容哈希去重、高相似记忆抑制。
- 项目隔离。
- 重要程度最多只提供 5% 加权。
- 不再根据访问次数调整排序。
- 返回匹配原因：标题匹配 / 标签匹配 / 正文匹配 / 语义相关 / 关联记忆扩展。

### 3.2 `memory_context` 质量

上下文组装不调用文本模型二次总结。处理步骤：

1. 检索候选。
2. 合并重复内容。
3. 使用 MMR 保证内容多样性。
4. 优先保留项目决策、用户偏好和高重要度记忆。
5. 根据字符预算裁剪。
6. 返回紧凑结构和引用 ID。
7. 标记每条记忆的召回原因。
8. 可选加入一跳关联记忆。

默认参数：

```
最大字符数：8000
服务端上限：30000
关联扩展：开启
最大关联记忆：5
```

### 3.3 MCP 工具

精简为 13 个：

```
memory_search
memory_get
memory_save
memory_archive
memory_recent
memory_context
memory_related

memory_candidate_submit
memory_candidate_list
memory_candidate_decide

project_list
project_resolve
project_save
```

关键调整：

- `memory_save` 同时负责创建和更新。
- `memory_archive` 使用布尔参数同时支持归档和恢复。
- `memory_related` 返回与指定记忆最相关的记忆及关联原因。
- `memory_candidate_decide` 使用 `CONFIRM` 或 `REJECT`。
- `project_save` 同时负责创建和修改。
- 工具响应保持紧凑，避免向 AI 返回管理端无关字段。
- 所有搜索和上下文结果返回 `matchReasons`。
- MCP Server Instructions 明确候选提交规则和禁止保存敏感信息规则。
- 只读和读写 Token、项目范围和过期时间继续保留。

### 3.4 记忆图谱

#### 节点

每个节点代表一条记忆：

```
id
title
scope
projectId
memoryType
importance
pinned
updatedAt
```

视觉编码：

- 节点颜色：所属项目。
- 个人记忆：固定中性色。
- 节点大小：重要程度。
- 外圈：收藏或置顶。
- 透明度：归档状态；默认不显示归档节点。
- 标签只在悬停和详情中显示，不单独形成节点。

#### 关系生成

不调用文本模型，复用检索信号：

```
综合关系分 =
语义相似度 × 0.60
+ 标签/关键词相似度 × 0.30
+ 同项目加权 × 0.10
```

无 Embedding 时：

```
综合关系分 =
标签/关键词相似度 × 0.80
+ 同项目加权 × 0.20
```

约束：

- "同项目"本身不能产生连线，只能增强已有关系。
- 语义相似度达到 0.72，或标签关键词相似度达到 0.50，才可成为候选关系。
- 每条记忆最多保存 8 条最强关系。
- 更新记忆或向量后只重算相关节点。
- 归档记忆默认移出图谱。
- 切换为"仅本地"时删除原有向量和纯语义关系。
- 删除记忆时级联删除关系。

#### 数据表

新增 `memory_edge`：

```
memory_id_a
memory_id_b
semantic_score
keyword_score
project_boost
combined_score
dominant_signal
updated_at
```

两个记忆 ID 始终按固定顺序存储，避免双向重复。

#### 图谱接口

```
GET /api/graph/neighborhood
GET /api/graph/project
POST /api/graph/rebuild
```

`GET /api/graph/neighborhood`：

```
memoryId
depth        默认 2，最大 2
limit        默认 120，最大 300
minScore     默认 0.60
```

返回：`nodes`、`edges`、`centerMemoryId`、`truncated`。

`GET /api/graph/project` 用于用户主动切换到项目总览，不作为默认视图。

#### 前端实现

使用 Canvas、d3-force、d3-quadtree，不引入大型图谱组件库。

交互：

- 鼠标滚轮缩放、拖动画布、拖动节点。
- 点击节点打开详情。
- 双击节点将其设为新中心。
- 悬停显示标题和关联原因。
- 筛选个人/项目。
- 调整最低关联度。
- 切换一跳/两跳。
- 一键回到中心节点。
- 一键复制中心记忆的 AI 上下文。

默认显示最多 120 个节点，硬上限 300 个，避免全库图谱变成不可读的"毛线团"。

## 五、动效与视觉规范

- 使用 CSS、Vue Transition、Canvas 和 `requestAnimationFrame`，不新增动画框架。
- 页面进入采用短暂淡入和 8 像素上移动，整体不超过 500ms。
- 记忆核心缓慢呼吸，客户端节点低频漂移。
- 真实 MCP 调用时显示一次连接脉冲，不制作无意义的粒子特效。
- 卡片悬停最多上浮 2 像素。
- 图谱进入后稳定布局，不持续抖动。
- 窗口最小化、页面不可见时暂停动画。
- 支持系统"减少动画"设置，关闭漂移、计数和缩放效果。
- 浅色、深色主题均使用低饱和青绿色与冷灰色，正文对比度不低于 4.5:1。

## 六、执行轮次与工期

### 第 1 轮：免登录桌面外壳与极简总览（3–4 天）

- 创建 .NET 10 四项目结构（WPF、WebView2、ASP.NET Core 同进程运行）。
- 实现单实例、托盘、窗口恢复、安全退出、端口选择和本地服务启动。
- 默认打开总览，不创建登录、账户或密码流程。
- 重组 Vue 为五项导航，建立浅色/深色主题和统一极简视觉规范。
- 完成总览静态内容、首次使用引导和动态记忆中枢原型。

验收：

- 双击 EXE 只出现客户端窗口，默认进入总览。
- 不打开系统浏览器，不出现任何登录或密码界面。
- 关闭窗口后 MCP 保持运行。

### 第 2 轮：SQLite 与高质量检索（6–8 天）

- 创建精简数据库（10 张表 + FTS5）。
- 实现记忆、项目、版本存储和中文单字、二元词组索引。
- 实现字段加权 BM25。
- 实现语义检索、Weighted RRF、去重、MMR 和上下文裁剪。
- 完成总览聚合接口，避免逐项目请求记忆（无 N+1）。
- 建立检索质量测试集。

验收：

- 中文精确词、短词和模糊词可用。
- 项目隔离 100% 正确。
- 无模型时关键词检索稳定。
- 2 万条数据关键词 P95 小于 100ms。
- 混合检索 P95 小于 500ms，不含模型网络耗时。
- 重启后数据完整。

### 第 3 轮：MCP 核心（5–7 天）

- 接入官方 C# MCP SDK，实现 Streamable HTTP 和 stdio。
- 实现 13 个精简工具。
- 实现 Token 权限（只读/读写）、项目范围和过期时间。
- 实现候选确认。
- 实现 MCP 配置生成、复制、吊销和测试。
- 对 Codex、Claude、Cursor、Trae 做真实连接验证。

验收：

- HTTP 和 stdio 行为一致。
- 工具 Schema 简洁、无冗余字段。
- 只读和项目权限正确。
- `memory_context` 严格遵守字符预算。
- AI 能理解每条结果为什么被召回。

### 第 4 轮：记忆图谱（5–7 天）

- 新增 `memory_edge`，实现关系计算和增量更新。
- 实现图谱 API。
- 实现 Canvas 力导向图，完成邻域、项目和筛选视图。
- 完成首页图谱预览与完整图谱联动。
- 将图谱扩展接入搜索与 `memory_context`。
- 新增 `memory_related` MCP 工具。

验收：

- 默认两跳邻域清晰可读。
- 单节点最多 8 条关系。
- 图谱不会因同项目形成全连接。
- 300 节点下拖动、缩放保持流畅。
- 仅本地记忆不产生云端语义关系。
- 图谱召回不会覆盖强关键词命中。

### 第 5 轮：桌面实用功能与设置（4–5 天）

- 快速记录、剪贴板预览保存。
- 主题和快捷键。
- 模型配置。
- 自动备份、恢复、导入导出。
- 一键复制 AI 上下文。
- SSE 状态更新、空状态、错误恢复和无障碍优化。
- 极简错误和状态提示。

验收：

- Token 和配置均可复制。
- 主要操作最多两层交互。
- 不出现独立任务、冲突和日志管理页面。

## 七、质量指标与固定边界

### 7.1 检索质量

建立至少 100 条中文测试查询及预期记忆：

- 关键词模式 Recall@5 不低于 0.75。
- 混合模式 Recall@5 不低于 0.85。
- 混合模式 MRR 不低于 0.75。
- 项目范围错误召回为 0。
- 完全无关查询不得返回高置信结果。
- 标题精确匹配必须位于第一名。
- 近重复内容只保留一条进入上下文。

### 7.2 MCP

- 13 个工具全部通过 HTTP 和 stdio 契约测试。
- 只读 Token 所有写操作拒绝。
- 项目范围覆盖搜索、保存、候选、关联和上下文。
- 客户端完全退出后，stdio 模式仍能独立运行。

### 7.3 图谱

- 默认 120 节点以内，最大 300 节点。
- 单记忆最多 8 条边。
- 图谱初次绘制小于 500ms，不含网络模型调用。
- 拖动和缩放目标保持 45–60 FPS。
- 图谱关系必须显示产生原因和分数。
- 图谱生成不额外调用文本模型。

### 7.4 轻量化

- 安装包目标不超过 100 MB。
- 空闲总内存目标不超过 250 MB。
- 空闲 CPU 长期低于 1%。
- 温启动进入总览页小于 4 秒。
- 不引入 Electron、Java、PostgreSQL、Redis、消息队列、Lucene 或大型图谱框架。

### 7.5 固定边界

- 只支持 Windows 10/11 x64。
- 单用户个人桌面版。
- 不迁移 PostgreSQL 数据。
- 版本号为 `0.3.0`。
- UI 保留 Vue，但重新做极简信息架构。
- 图谱以记忆节点为主，项目只负责分组着色。
- 图谱关系复用检索信号，不使用文本模型生成。
- 图谱默认从当前记忆展开两跳。
- "高可用"指本地数据可靠、崩溃恢复、自动备份和模型降级，不指服务器集群。

## 八、验收标准

- 双击程序后直接进入总览，不出现登录、账号或初始密码。
- 本地页面只在本机可访问；MCP 仍必须携带有效 Token。
- 总览展示真实记忆、项目、候选、MCP 状态和图谱预览。
- 动效克制、流畅，并尊重系统减少动画设置。
- 关键词检索在未配置模型时可完整使用。
- MCP 可安全查询、写入和处理候选记忆。
- 应用崩溃重启后 SQLite 数据保持可用。
- 安装版无需用户安装 Java、Node、Docker 或数据库。

## 九、默认假设

- 首版为单用户、仅 Windows 10/11 x64。
- 任何能够登录同一 Windows 账户的人均可打开本地记忆管理界面；这是删除登录后的明确取舍。
- 如未来需要防止他人使用同一电脑访问，可增加可选"应用解锁密码"，但首版不实现。
- MCP Token、模型 API Key 和备份文件仍属于敏感信息，Token 不因取消登录而改为公开。
- "高可用"指本地数据可靠、崩溃恢复、自动备份和模型降级，不指服务器集群。
